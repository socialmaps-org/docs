# Get Started

## What is Social Maps?
Social Maps is a free ([as in freedom](https://en.wikipedia.org/wiki/Free_content)) database for crowd-sourced reviews about points of interest (POI) in [OpenStreetMap](https://www.openstreetmap.org/).
