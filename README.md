# Social Maps Documentation

We use [MkDocs](https://www.mkdocs.org/) and [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) to generate a static site for our documentation. Our API Reference uses a different software called [Scalar](https://scalar.com/), which is a JavaScript application that renders our API Reference client-side based on our OpenAPI spec.

We use [uv](https://docs.astral.sh/uv/) as our Python package manager for managing MkDocs and Material for MkDocs.
